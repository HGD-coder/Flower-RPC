# Flower-RPC

## 项目来源与定位

Flower-RPC 是一个用于学习 RPC 原理与 Java 网络编程的教学型实现。

本项目参考 [Snailclimb/guide-rpc-framework](https://github.com/Snailclimb/guide-rpc-framework)，跟随其架构、模块划分和实现思路逐步学习与复现，并非完全独立起源的 RPC 框架。

项目仍在学习和开发中，尚未完成。目前未进行差异化重构或功能扩展，整体内容与上游项目较为一致。

上游项目采用 Mulan PSL v1 许可证。本仓库保留了许可证副本；上游代码及相关权利归原作者和贡献者所有。

## 正在学习与计划覆盖的内容

- RPC 调用流程、动态代理和服务发布
- Socket、Netty 网络传输与连接管理
- 自定义协议、编解码、序列化和压缩
- 服务注册发现与负载均衡
- 心跳检测、统一配置、测试和性能验证

本项目仅用于学习和技术交流，与上游作者无隶属或官方合作关系。
